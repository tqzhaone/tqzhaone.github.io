连接 GitHub

后台通过 GitHub 修改网站：每次发布都是仓库 tqzhaone/tqzhaone.github.io 里的一次提交，大约一分钟后自动上线。

怎么生成密钥（只需要一次）
  1. 打开 GitHub 的「新建细粒度密钥」页面（要先登录 GitHub）。
  2. Token name 填「网站后台」；Expiration 选个期限，比如一年，到期后再生成一个。
  3. Repository access 选 Only select repositories，只勾 tqzhaone.github.io。
  4. Permissions → Repository permissions → Contents 选 Read and write，其他都不用动。
  5. 点最下面的 Generate token，复制以 github_pat_ 开头的那串字符，粘贴到上面。

密钥只存在这台设备的浏览器里，不会上传到网站；它只能改这一个仓库。用完公用设备记得点右上角「退出」。万一怀疑泄露，到 GitHub 的 密钥列表 里删掉它，再生成一个。
